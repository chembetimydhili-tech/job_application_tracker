# Job Application Tracker

A Python-based application to track and manage job applications.

## About the Project
The Job Application Tracker helps users maintain a record of their job applications in one place. It provides a simple menu-driven interface to add new applications and view existing applications.

## Features
- Add job applications
- View saved applications
- Simple menu-driven interface
- Exit the application

## Technologies Used
- Python

## How to Run
1. Install Python on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

   python app.py

## Project Structure
- app.py — Main application file
